# Online Calc Question "Finder"

Basic purpose it to take queries from someone about specific topics for calc questions and then it parses the web to find "interesting" and/or challenging questions so the calc teacher doesn't have to create said questions.

Built in collaboration with a highschool math teacher of mine, it was originally a group project but I dedicated part of my senior year to fixing it up to have a proper UI amongst some other features.

Saw limited use as part of several test runs, ultimately not adopted widely, but a fun small project nonetheless.

Ended up being a pretty worthwhile investment considering the calc teacher I made this for gave me a recc for college!
